# 🍏 OS X Yosemite EFI Mounter

A lightweight, zero-dependency command-line utility to quickly list, mount, and unmount EFI partitions on **OS X Yosemite (10.10)** and later.

## 🚀 Usage

Make the script executable and run directly from the terminal:

```bash
# Clone the repository
git clone https://github.com/EiJackGH/efi-mounter.git
cd efi-mounter

# Grant execute permissions
chmod +x efi-mounter
